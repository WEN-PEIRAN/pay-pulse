薪跳 PayPulse V1.2

使用方法
1. 将整个文件夹上传到 GitHub 仓库。
2. 在仓库 Settings > Pages 中发布网站。
3. 使用 iPhone Safari 打开网址，然后从分享菜单选择“添加到主屏幕”。

本地测试
直接打开 index.html 可以查看主要功能。离线缓存和“添加到主屏幕”应通过 HTTPS 网站测试。

隐私
本版本无需注册，不设置用户数据库，不会主动上传工资设定或事件记录。数据保存在当前浏览器的 localStorage 中。清除 Safari 网站数据、使用隐私浏览或点击 App 内“清除全部数据”会删除记录。

V1.0 功能
- 中文和英文界面
- 蜜桃心跳、晴空心跳两套主题
- 多种收入周期、税前/税后标签及币种
- 固定工作时间、工作日、无薪休息
- 今日收入、每秒收入、进度、下班倒计时
- 工资每跨过一分钱时触发心跳视觉动画
- 带薪事件计时、结算、记录与简单统计
- 一键隐藏金额
- PWA 主屏幕与离线缓存基础支持

V1.1 更新

- 英文主按钮缩短为“Start Event”。

- 八类带薪事件全部加入统一画风的动物插图。
- 摸鱼改为小猫伸爪摸鱼缸中的鱼。
- 计时、结算、记录及统计页面同步使用动物插图。
